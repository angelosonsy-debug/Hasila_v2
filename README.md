# حصيلتي — تطبيق مذاكرة مفردات الإنجليزي

**تصميم وتطوير: Angelos Onsy**

مشروع React + Vite + Capacitor جاهز يتحول لملف APK عن طريق GitHub Actions (مفيش حاجة تتبني على جهازك، كله بيحصل على السيرفر).

## المحتوى
- `src/App.jsx` — التطبيق بالكامل (القاموس، الفلاش كاردز، SM-2، الإعدادات، التذكير)
- `capacitor.config.json` — اسم التطبيق و package id (`com.hasila.vocab`) — غيّرهم قبل أول بناء لو حابب
- `.github/workflows/android.yml` — الأتمتة اللي بتبني الـ APK تلقائيًا

## الخطوات

### 1) اعمل ريبو على GitHub
1. ادخل github.com وسجل دخول (أو اعمل حساب لو معندكش)
2. اضغط **New repository**
3. سمّيه مثلاً `hasila-vocab-app`، خليه **Private** لو حابب، من غير ما تضيف README أو .gitignore (المشروع جاهز بيهم)
4. اضغط **Create repository**

### 2) ارفع المشروع
لو عندك git على جهازك:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/hasila-vocab-app.git
git push -u origin main
```

(غيّر `USERNAME` باسمك على GitHub)

**لو معندكش git — ارفع بالسحب والإفلات من المتصفح مباشرة:**
1. فك ضغط الملف اللي بعتهولك على جهازك
2. **مهم**: خلّي المتصفح/مستكشف الملفات يعرض **الملفات المخفية** (فولدر `.github` اسمه بيبدأ بنقطة فبيتخبى افتراضيًا) — على ويندوز: من قائمة View فعّل Hidden items، على ماك: Cmd+Shift+نقطة
3. في صفحة الريبو الفاضية على GitHub، اضغط **uploading an existing file**
4. افتح فولدر المشروع اللي فككت ضغطه، اختار **كل اللي جواه** (Ctrl+A أو Cmd+A) — يعني `index.html`, `package.json`, `src`, `.github`, `.gitignore`... إلخ كلهم مع بعض
5. اسحبهم كلهم مرة واحدة على منطقة الرفع في GitHub (مش الفولدر نفسه، لازم تكون الملفات في جذر الريبو مباشرة مش جوه فولدر باسم المشروع)
6. تأكد إن `.github/workflows/android.yml` ظهر في القائمة قبل ما تعمل commit — لو مش ظاهر يبقى الفولدر المخفي معملوش drag، ارجع لخطوة 2
7. اكتب رسالة commit واضغط **Commit changes**

بمجرد الـ commit، الـ Action هيشتغل لوحده أوتوماتيك.

### 3) تابع البناء
بمجرد الـ push، البناء هيشتغل تلقائيًا. تقدر تتابعه من تاب **Actions** فوق في صفحة الريبو. أول مرة ممكن ياخد 3-5 دقايق.

لو حابب تشغّله يدويًا بعد كده من غير push جديد: من تاب Actions اختار workflow اسمه "Build Android APK" واضغط **Run workflow**.

### 4) نزّل الـ APK
لما البناء يخلص (علامة ✓ خضرا)، افتح الـ run نفسه، هتلاقي تحت **Artifacts** ملف اسمه `hasila-vocab-debug-apk` — نزّله (هيكون ملف zip فيه الـ APK جواه).

### 5) ثبته على موبايلك
1. انقل ملف الـ APK لموبايلك (تيليجرام لنفسك، جوجل درايف، أو كابل)
2. لما تفتحه، أندرويد هيقولك محتاج تسمح بتثبيت تطبيقات من مصدر غير معروف — وافق مؤقتًا لتطبيق اللي فتحت بيه الملف
3. اضغط تثبيت

## ملاحظات مهمة
- **التذكير اليومي**: بيتظبط من جوه التطبيق نفسه (زرار ⚙️)، وبيستخدم `@capacitor/local-notifications` عشان يبقى تنبيه حقيقي من نظام أندرويد حتى لو التطبيق مقفول. أول مرة هيطلب إذن الإشعارات — لازم توافق عشان يشتغل.
- **الخطوط**: خطوط Cairo و Space Mono متضمّنة جوه التطبيق (بدون أي اتصال بالإنترنت أو Google Fonts).
- **تغيير اسم التطبيق أو الـ package id**: عدّل `appId` و `appName` في `capacitor.config.json` قبل أول push.

## لو البناء فشل (Actions أحمر)
ابعتلي رسالة الخطأ من لوج الـ Actions (اضغط على الخطوة اللي فشلت هتلاقي تفاصيل حمرا) وهساعدك نصلحها خطوة بخطوة — إصدارات Node/Java/Gradle أحيانًا محتاجة ضبط حسب إصدار Capacitor.
