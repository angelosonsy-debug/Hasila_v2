

# حصيلتي | Hasila

تطبيق لتعلّم ومراجعة مفردات اللغة الإنجليزية باستخدام البطاقات التعليمية ونظام المراجعة المتباعدة، مبني باستخدام React وVite وCapacitor.

**تطوير: Angelos Onsy**

## المميزات

- **قاموس المفردات:** تنظيم الكلمات حسب المستوى والتصنيف.
- **البطاقات التعليمية (Flashcards):** مراجعة الكلمات ومعانيها وأمثلتها.
- **المراجعة المتباعدة:** استخدام خوارزمية SM-2 لتنظيم مواعيد مراجعة الكلمات.
- **متابعة التقدم:** تصنيف الكلمات إلى جديدة ومعروفة وتحتاج إلى مراجعة.
- **إعدادات المذاكرة:** تخصيص تجربة التعلّم والإعدادات المتاحة داخل التطبيق.
- **التذكيرات اليومية:** إشعارات محلية لتذكير المستخدم بمراجعة المفردات.
- **دعم العربية والإنجليزية:** واجهة عربية وخطوط مضمّنة داخل التطبيق.

## التقنيات المستخدمة

- React
- Vite
- JavaScript
- Capacitor
- Capacitor Local Notifications
- GitHub Actions لبناء تطبيق أندرويد تلقائيًا.

## بناء تطبيق أندرويد

يستخدم المشروع GitHub Actions لتنفيذ عملية البناء على خوادم GitHub، دون الحاجة إلى تثبيت Android Studio على الجهاز.

1. افتح مستودع المشروع على GitHub.
2. انتقل إلى تبويب **Actions**.
3. افتح عملية البناء المسماة **Build Android APK**.
4. انتظر حتى تنتهي العملية بنجاح.
5. افتح عملية التشغيل، ثم انتقل إلى قسم **Artifacts**.
6. نزّل الملف `hasila-vocab-debug-apk` وفك ضغطه للحصول على ملف APK.

يمكن تشغيل عملية البناء يدويًا من خلال خيار **Run workflow** إذا كان متاحًا في المستودع.

## تثبيت التطبيق

1. انقل ملف APK إلى هاتف أندرويد.
2. افتح الملف واتبع تعليمات التثبيت.
3. اسمح بالتثبيت من المصدر المحدد إذا طلب نظام أندرويد ذلك.
4. افتح التطبيق وامنحه إذن الإشعارات عند الطلب لتفعيل التذكيرات.

**ملاحظة:** نسخة Debug مخصصة للتجربة والتثبيت المباشر، ولا تُعد نسخة Release موقّعة وجاهزة للنشر على Google Play.

## إعدادات التطبيق

تُحفظ إعدادات Capacitor في الملف `capacitor.config.json`، وتشمل:

- **اسم التطبيق:** `Hasila`
- **معرّف التطبيق:** `com.hasila.vocab`

## التذكيرات والإشعارات

يعتمد التطبيق على `@capacitor/local-notifications` لإرسال الإشعارات المحلية. يعتمد عملها على منح الأذونات اللازمة وإعدادات نظام أندرويد، وقد تختلف بعض التفاصيل باختلاف إصدار النظام.

## استكشاف أخطاء البناء

عند فشل عملية البناء:

1. افتح تبويب **Actions** في GitHub.
2. اختر عملية التشغيل التي فشلت.
3. افتح الخطوة التي تحمل علامة الخطأ.
4. راجع سجل التنفيذ لتحديد سبب الفشل.

قد ترتبط المشكلة بإصدارات Node.js أو Java أو Gradle أو Capacitor، أو بإعدادات المشروع.
